# renderers/ 就地规则

> 违反以下任意一条，就等于毁掉"渲染器可整块替换"这个能力。
> 完整文档：`docs/modules/renderer.md`

1. **不得引用 Vue 或任何 UI 框架。** 接口只认「契约数据 + 一个挂载容器」。
   实现内部可以用库，但接口不许绑框架。
2. **必须实现 `appendData`**，即使当前只被调用一次（将来的实时功能要靠它接上）。
3. **禁止为显示流畅做抽样。** 可见点数超过像素列数时，按像素列取 min/max。
4. **遇到不认识的轴类型要降级并标注**，不得崩溃、不得静默。
5. **Canvas 不是响应式的**：数据变了必须显式重绘，不要套用 Vue 的响应式思维。
6. 坐标轴、图例、tooltip、选区框由渲染器自己用原生 DOM 创建，**不要推给 UI 层**。

改完记得更新 `docs/modules/renderer.md`，并在 `docs/DEVLOG.md` 追加一条。
