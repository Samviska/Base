# 技术栈与硬性要求

> **本文件是技术要求清单**：用什么、锁什么版本、什么被禁止。
> "为什么这么定"在 [DECISIONS.md](DECISIONS.md)，这里只写结论。
> 标注 **待确认** 的条目**尚未拍板，不得据此开工**。

---

## 1. 已定的技术选型

| 层 | 选型 | 约束 |
| --- | --- | --- |
| 后端语言 | **Python** | — |
| 前端框架 | **Vue 3（组合式 API）** | 锁定主版本与写法，**不得混用 Vue 2 / 选项式** |
| 前端构建 | **Vite** | dev server 用于开发；build 只用于交付 |
| 前端语言 | **JavaScript + JSDoc 类型注释** | 不引入 TypeScript 编译 |
| 图形绘制 | **Canvas 2D**（内置实现） | 渲染器**接口**不绑定任何绘图技术，可整块替换 |
| 前后端通信 | **单条 WebSocket** + JSON 信封 | HTTP 仅用于加载页面与静态资源 |
| 数据存储（V1） | **JSON** | 接口按"按 x 范围读取"定义，可加格式 |
| 契约定义 | **JSON Schema**（语言中立） | 放 `contract/schema/` |

---

## 2. 明确禁止

| 禁止事项 | 原因 |
| --- | --- |
| 渲染器**接口**依赖 UI 框架 | 换框架时所有渲染插件（含第三方）会作废 → [DECISIONS](DECISIONS.md) D3 |
| 用 SVG 承载大数据 | 每个点一个 DOM 节点，到万级就明显吃力 |
| 为显示流畅做抽样 | 会抹掉尖峰，而问题就在尖峰上 |
| 后端出现界面相关内容 | 违背分层 → [ARCHITECTURE](ARCHITECTURE.md) §1 |
| 打包进入开发流程 | 开发循环必须是"改代码 → 运行 → 看结果" → D10 |
| 存储接口名里带格式 | 加格式时要改所有调用点 → D6 |
| 读写时丢弃契约未知字段 | 插件的扩展信息会静默消失 |
| 依赖版本使用 `^` / `~` | 避免"某天它自己变了" |
| TypeScript 编译流程 | 少一层工具链（**可复议**，需要时再评估） |
| Sass / Less | 用原生 CSS 变量替代 |

---

## 3. 依赖管理

| 项 | 要求 |
| --- | --- |
| 前端依赖 | 仅限 `package.json` 中声明；**版本号写死**，不用 `^` / `~` |
| 渲染器所需第三方库 | 库文件**随项目提供**（放 `libs/`），不走 npm 安装流程 |
| 后端依赖 | **待确认**：`requirements.txt`（最简单）或 `pyproject.toml` + `uv`（更现代） |

---

## 4. 开发与交付流程

| 阶段 | 要求 |
| --- | --- |
| **开发** | **改完即见**，不需要手动构建或打包。这是不可退让的体验要求 |
| **交付** | 一条命令产出单个 exe；**打包后插件机制必须仍然可用**（一票否决项） |

---

## 5. 尚未确定（需要拍板）

| 项 | 建议 | 影响 |
| --- | --- | --- |
| Python 版本 | 3.11 起（该版本起 CPython 有明显性能优化） | 可用语法与依赖选择 |
| 后端依赖管理方式 | 见 §3 | 环境搭建与打包方式 |
| 代码格式化 / 静态检查 | Python 侧先只用 ruff；前端暂不引入 lint | 协作一致性，可后补 |
| 测试框架 | Python 用 pytest；前端用 Vitest | "插件自检方式"的实现 |

> 上表未定项**不阻塞文档工作，但阻塞写代码**。
