# 给 AI 的编码规则

> **状态**：骨架，待补全。
> 本文件是**每次动手前必读**的规则集。

---

## 1. 本项目的高频错误（先看这张表）

| 错误做法 | 正确做法 | 为什么 |
| --- | --- | --- |
| 在 `mousemove` / `wheel` 事件里直接发数据请求 | `requestAnimationFrame` 节流 + 代次作废 | 否则产生**请求风暴**，交互反而更卡（[protocol.md](../protocol.md) §4） |
| 改了数据但 Canvas 没重绘 | 数据变化后**显式重绘** | Canvas 不是响应式的，套用 Vue 思维必然出 bug |
| 渲染器里 `import` Vue | 渲染器只认「契约数据 + 挂载容器」 | 接口绑框架 → 所有渲染插件作废 |
| 在界面代码里做业务判断 | 判断放后端，界面只渲染状态 | 否则改界面会牵动逻辑 |
| 把滤波放在聚合之后 | 提取 → 滤波 → **聚合** | 滤波必须作用于全量数据，否则**结果是错的** |
| 为显示流畅做抽样 | 像素列 min/max | 抽样会抹掉尖峰，而问题就在尖峰上 |
| 存储接口名里带格式（`load_json_file`） | 按需求命名（`open_source`） | 否则加格式时要改所有调用点 |
| 读写时丢弃不认识的字段 | 原样保留 | 否则插件的 `extensions` 静默消失 |
| 静默降级（未知轴类型当普通数值轴画） | 降级 + **界面明确标注** | 静默降级会让人误判图形含义 |
| 交付只给打包产物或单文件脚本 | 给完整可读的工程结构 | 见 [README.md](../README.md) |

## 2. 两处最容易写错的地方（示例代码已就位）

| 位置 | 实现 | 用例 |
| --- | --- | --- |
| **节流 + 代次作废**（前端数据请求） | `frontend/api/viewport-loader.js` | `frontend/tests/viewport-loader.test.js` |
| **像素列 min/max 聚合**（后端） | `backend/aggregate/pixel_columns.py` | `backend/tests/test_aggregate.py` |

> 这两处光有文字规则不够。前者写错就变成"每个 `mousemove` 发一次请求"，
> 交互越缩放越卡；后者写错会抹掉尖峰——而尖峰正是要找的问题。

## 3. 交付要求

1. 完整可读的工程结构，不接受只给打包产物或单文件脚本。
2. 新增能力优先以插件形式实现；改核心必须书面给出理由。
3. 每个插件自带：示例输入、期望输出、自检方式。
4. 同步更新受影响的文档，并在 [DEVLOG.md](../DEVLOG.md) 追加一条。
5. **默认交付形态是"能直接跑起来"，不是"打好的包"。**
