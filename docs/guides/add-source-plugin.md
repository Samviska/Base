# 怎么加一个数据源插件

> **状态**：待建。前置：先读 [modules/source.md](../modules/source.md)。

---

## 适用场景

出现一种新的日志格式需要解析；或将来要做实时数据流（持续模式）。

## 前置条件

- 已读 [modules/source.md](../modules/source.md)
- 已读 [contract.md](../contract.md)（输出必须符合契约）
- 手头有**真实日志样本**（不要凭想象写解析）

## 步骤（待补全）

1. 复制模板目录（**待建**：`plugins/sources/_template/`）
2. 实现 `extract(path, options) -> 契约数据`
3. 声明 x 轴描述（注意 `origin` 与精度）
4. 写 manifest
5. 自检输出是否符合契约

## 验证方式（待补全）

- 输出的数据能通过校验器，**零违规**
- 同一输入跑两次，结果**完全一致**
- 在界面上选中该插件即可出图，**核心代码零改动**

## 常见错误

| 现象 | 原因 |
| --- | --- |
| 波形被压缩或拉伸 | 时间精度搞错（微秒当毫秒） |
| x 轴乱序、缩放行为异常 | 日志有乱序行，未排序也未记录 |
| 曲线出现假的 0 值 | 缺失值用了 `0` 而不是 `null` |
| 尖峰消失 | 解析时跳过了异常点 |
