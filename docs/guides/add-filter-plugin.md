# 怎么加一个滤波插件

> **状态**：待建。前置：先读 [modules/filter.md](../modules/filter.md)。

---

## 适用场景

需要一个新的数据处理算法（滑动平均、中值、去趋势、单位换算等）。

## 前置条件

- 已读 [modules/filter.md](../modules/filter.md)
- 明确该算法**是否需要前后文**（有状态算法尤其要注意）

## 步骤（待补全）

1. 复制模板目录（**待建**：`plugins/filters/_template/`）
2. 实现 `apply(data, params) -> data`（**纯函数，不得修改输入**）
3. 实现 `declare_params() -> 参数声明[]`（界面据此自动生成控件）
4. 写 manifest
5. 用示例数据自检

## 验证方式（待补全）

- 输入数据在调用后**未被修改**（可用不可变检查或深比较验证）
- 参数可在界面调节，**无需改核心或界面代码**
- 关闭滤波后数据恢复原样

## 常见错误

| 现象 | 原因 |
| --- | --- |
| 关闭滤波后数据没恢复 | 原地修改了输入数组 |
| 边界数据失真 | 只拿到视口数据，缺前后文——滤波必须拿全量 |
| 拖了滑块图没变 | 参数变化未触发缓存失效 |
| 界面控件没生成 | `declare_params` 的类型/范围/默认值不完整 |
