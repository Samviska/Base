# 模块：聚合（Aggregate）

## 1. 一句话职责

把全量数据按「**视口范围 + 目标分辨率**」降维成"绘制数据"。

**不负责**：滤波（它作用于全量，**在聚合之前**）、绘制。

## 2. 代码位置

| 内容 | 路径（规划） |
| --- | --- |
| 聚合算法与缓存 | `backend/aggregate/` |

## 3. 对外接口

```
aggregate(series, range, resolution) -> { points, aggregated: bool }
```

- `range`：视口范围
- `resolution`：目标分辨率，通常是画布像素宽度
- `aggregated`：本次是否发生了聚合（供界面标注）

## 4. 依赖规则

| | |
| --- | --- |
| 可以依赖 | 契约、后端缓存 |
| **禁止依赖** | 界面、渲染器、具体存储实现 |

## 5. 扩展点

策略本身可替换（当前是像素列 min/max）。
**替换时必须保持"不丢极值"这一性质**——这是硬性要求，不是实现细节。

## 6. 本模块的硬规则

1. **禁止抽样**：不得等间隔取点、不得取均值、不得随机取点。
2. **像素列 min/max**：每一列取落在该列内所有点的**最小值与最大值**。
   - 正例：某列内有 5000 个点，其中一个是尖峰 → 输出 `(min, 尖峰)`
   - 反例：某列内取第 2500 个点作为代表 → 尖峰丢失
3. **点数未超过分辨率时直接返回原始点**，不要做无意义的聚合。
4. **必须在返回值里带"是否聚合"标志**，供界面按 [ARCHITECTURE.md](../ARCHITECTURE.md) §4 的要求标注。
5. **视口外的数据不参与计算**（视口裁剪）。
6. `null` 不参与 min/max 计算。

## 7. 已知的坑

| 坑 | 现象 | 应对 |
| --- | --- | --- |
| 每次缩放都重新全量扫描 | 大数据下缩放卡顿 | 缓存聚合结果；必要时建多级聚合金字塔 |
| 列边界的浮点处理 | 相邻列重复计算或漏掉边界点 | 明确"半开区间"的列定义，并写边界测试 |
| `null` 污染 min/max | 图形出现假的极值 | 跳过 `null` 后再比较 |
| 多序列共享 x 轴时重复扫描 | 性能浪费 | x 相同则一次扫描，同时产出各序列的聚合结果 |
