# 模块：后端核心（Core）

## 1. 一句话职责

编排各环节：**会话状态、缓存与失效、插件注册、命令分发**。

**不负责**：具体的数据处理（那是各插件与[聚合](aggregate.md)模块的事）。

## 2. 代码位置

| 内容 | 路径 |
| --- | --- |
| 会话状态与三层缓存 | `backend/core/session.py` |
| 命令分发（消息 → 响应） | `backend/core/dispatch.py` |
| 错误码与领域错误 | `backend/core/errors.py` |
| **过渡**数据源入口（直接读契约 JSON） | `backend/core/source.py` |
| 用例 | `backend/tests/test_core.py` |

## 3. 对外接口

```python
from backend.core import Session, handle

response = handle(session, request_envelope)   # 同步函数：返回响应信封，或 None
```

| 返回值 | 含义 |
| --- | --- |
| 响应信封 `{id, type, ok, payload \| error}` | 请求已处理。**成功与失败都要回** |
| `None` | 不是可配对的消息（缺 `id`、类型不对、事件方向的消息）——由服务端记日志 |

一次连接一个 `Session`：持有当前数据集、数据源引用、滤波链与三层缓存。

**命令实现状态**（清单见 [messages.md](../messages.md)）：

| 状态 | 消息 |
| --- | --- |
| 已实现 | `list_plugins`、`open_file`、`close_source`、`list_storage_formats`、`query_range`、`get_filter_chain`、`set_filter_chain` |
| 未实现 | 标注四条（M9–M12）与会话两条（M13、M14）属第 6 批：回 `INTERNAL` 并说明尚未实现 |
| 未登记类型 | 回 `UNKNOWN_TYPE` |

错误码与 `detail` 的规则见 [messages.md](../messages.md) §2；契约违规**必须**带字段路径。

### 3.1 缓存与失效

| 层 | 存什么 | 什么时候失效 |
| --- | --- | --- |
| 提取 | 数据集（不在缓存里，就是 `session.dataset`） | 换文件 / 关闭数据源 |
| 滤波 | 滤波后的全量数据，键为 `chain_key` | 链的顺序、开关、参数任一变化；换文件 |
| 聚合 | 某（序列集合, 范围, 分辨率）的结果 | 换文件；改滤波链 |

**失效单向**：上层变化让下层失效，反向不成立。
聚合缓存**有上限**（32 条，超出淘汰最久未用的）：拖拽缩放会持续产生新键，不设上限就是内存泄漏。
换文件时**保留滤波链配置**——换一个文件通常还想用同一套滤波。

### 3.2 过渡：数据源入口

`open_file` 目前直接读**契约 JSON 文件**（`source.py`），因为数据源插件机制（第 2 批）尚未落地；
请求带 `source_plugin` 时回 `PLUGIN_NOT_FOUND`。
插件机制就绪后删掉 `source.py`、改为调插件注册表，**命令层的请求与响应形状不变**。

## 6. 本模块的硬规则

1. **只依赖插件接口，不认识任何具体插件。**
2. **缓存失效必须单向**：换文件 → 提取失效 → 连带滤波、聚合失效；反向不成立。
   | 层 | 失效条件 |
   | --- | --- |
   | 提取结果 | 换输入文件 / 换数据源插件 |
   | 滤波结果 | 滤波链或参数变化 |
   | 聚合结果 | 视口变化 |
3. **会话必须可保存与重开**：数据源引用 + 滤波链参数 + 标注 + 视图状态。
4. **插件异常隔离**：捕获、记录并向界面呈现，**不向主流程传播**。
5. **无插件的空目录也是合法状态**，应用仍要能启动。

## 7. 已知的坑

| 坑 | 现象 | 应对 |
| --- | --- | --- |
| 缓存失效不全 | 换了文件但图没变 | 失效规则写成上表并有测试覆盖 |
| 会话文件存绝对路径 | 换机器打不开 | 存相对路径或纯文件名 |
| 插件加载顺序影响结果 | 行为不稳定、难复现 | 注册与执行解耦；执行顺序由使用者在界面上编排 |
| 错误只写日志不给界面 | 使用者不知道发生了什么 | 错误必须**同时**进日志与界面 |
| 会话里塞入全量数据 | 会话文件巨大 | 会话只存**引用与参数**，数据留在原文件 |
| 聚合缓存不设上限 | 拖拽缩放后内存持续增长 | 按最久未用淘汰，上限 32 条；键是（序列集合, 范围, 分辨率） |
| 处理函数抛异常后没响应 | 前端永远停在加载中 | `handle` 兜底捕获一切异常并回 `INTERNAL`——异常路径也必须有响应 |
| 分类轴直接取 min/max | 字符串不可比，`x_range` 抛异常 | 分类轴按索引给范围 `[0, n-1]`，与聚合的索引约定一致 |
