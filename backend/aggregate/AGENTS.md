# aggregate/ 就地规则

> 本模块决定"图上看不看得到问题"，规则不容打折。
> 完整文档：`docs/modules/aggregate.md`

1. **禁止抽样。** 不得等间隔取点、取均值、随机取点——
   那会抹掉尖峰与单点异常，**而问题恰恰就在尖峰上**。
2. **像素列 min/max。** 每一列取落在该列内所有点的**最小值与最大值**。
3. 点数未超过分辨率时**直接返回原始点**，不做无意义的聚合。
4. 返回值必须带 `aggregated` 标志，界面据此标注"当前处于聚合显示状态"。
5. `null` 不参与 min/max 计算。
6. 视口外的数据不参与计算（视口裁剪）。
