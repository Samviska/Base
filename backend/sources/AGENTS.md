# sources/ 就地规则

> 完整文档：`docs/modules/source.md`

1. **必须自校验**输出是否符合契约。不合规时**报错并给出出错字段路径**，
   不能只说"数据不合法"。
2. **结果必须可复现**：同一输入 + 同一插件版本 = 同一输出。
3. **缺失值用 `null`**，禁止用 `0` / `-1` / 空串代替——否则波形会出现假数据。
4. **时钟跳变或回绕必须显式处理**，并把处理方式记入 `meta.notes`。
   不得静默产生一条乱序的 x 轴，那会让整张图失去意义。
5. 只有相对上电时间的日志，用 `origin: start` + 数值毫秒，**不要伪造绝对时间**。
6. **不得跳过异常点**（尖峰正是要发现的东西），也**不得直接操作界面**。
7. 解析失败要把异常转成可读信息：第几个文件、第几行、期望什么格式。
