# JP18 三电极心电日志插件

把设备的**十六进制文本日志**解析成契约数据。

## 包结构

用真实日志反推（320 个子包包头零失配、样本数正好整数）：

| 段 | 长度 | 说明 |
| --- | --- | --- |
| 包头 | 1 字节 | 固定 `0x88` |
| 样本 | 66 组 × 3 字节 = 198 字节 | 每组**大端有符号 24 位**（即"3 字节合成有符号 32 位整型"，高位符号扩展） |
| 填充 | 视情况 | 样本不足 66 组时，用 `80 80 80` 组补齐 |
| 末尾 | 4 字节 | 不解析 |

子包总长固定 **203 字节**（与 1624 = 8 × 203 的读取缓冲对上）。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `channel_name` | `ECG` | 序列名 |
| `unit` | `1` | 纵轴单位；原始 ADC 值无量纲，写 `1` |
| `sample_rate` | `0` | 采样率 Hz；**0 = 横轴用采样序号**，> 0 时换算成毫秒（`origin: start`） |

## 自检

```powershell
.venv\Scripts\python.exe -m unittest backend.tests.test_sources -v
```

用例用**合成日志**（不依赖真实设备文件），覆盖包结构、填充跳过、负值、横轴选择与可复现性。

## 已知限制

- 横轴默认是采样序号：日志里没有采样率字段，硬凑毫秒会让波形含义失真
- 只取一个通道；一个文件对应一条序列（多文件对比属本期外）
- 值未做物理量换算：`unit` 默认 `1`，需要 mV 之类请自行填参数
