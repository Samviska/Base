# 脚本

启动、构建、打包等辅助脚本。

## 用途

| 用途 | 说明 |
| --- | --- |
| **开发期启动** | 起后端服务 + 前端 dev server。**日常开发只用这一个** |
| **交付打包** | 产出单个 exe。**只在交付时用** |

## 规则

1. **打包不得进入开发流程。**
   开发循环必须是"改代码 → 运行 → 看结果"，不是"改代码 → 打包 → 运行"。
2. **打包后插件机制必须仍然可用**——往插件目录放一个脚本，不改 exe、不重新打包，要能生效。
   这是**一票否决项**：若打包后只能跑内置功能，"AI 持续写插件"的形态在交付形态下就失效了。
3. 脚本必须有注释说明**用途与前置条件**。
4. 脚本不得把参数、路径硬编码成只适用于某台机器。
